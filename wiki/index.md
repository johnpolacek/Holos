# Holos Project Wiki

This wiki is the deep documentation layer for Holos. Read this page first to find durable project notes before falling back to repo files.

At bootstrap, the inspected repo shows Holos as a Next.js content site for the Holos interpretive framework with main sections for overview, logic, predictions, and citations, plus a generated `public/holos.pdf` artifact.

## How To Use This Index

- start here when answering questions about Holos internals
- keep entries short, durable, and grounded in the repo
- add new durable pages here when the project wiki grows
